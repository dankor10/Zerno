# ЗЕРНО — сайт кофейни (Vue 3 + Vite)

## Запуск в VS Code

1. Открой папку `zerno-coffee` в VS Code.
2. Открой встроенный терминал (`` Ctrl+` ``) и выполни:

   ```bash
   npm install
   npm run dev
   ```

3. Открой ссылку из терминала (обычно `http://localhost:5173`) — сайт с горячей перезагрузкой.

## Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/` — их можно загрузить на любой хостинг.

## Структура проекта

```
src/
  App.vue                     — собирает все секции вместе
  style.css                   — общие токены (цвета, шрифты), шапка, футер, герой
  config.js                   — DEMO_MODE и список временных слотов для брони
  components/
    AppNav.vue                — навигация + мобильное меню
    HeroSection.vue           — главный экран
    AboutSection.vue          — о нас
    FlavorWheel.vue           — интерактивное колесо вкуса (фильтрует меню)
    MenuSection.vue           — меню карточками-бирками
    ProcessSection.vue        — график кривой обжарки
    GallerySection.vue        — доска с "приколотыми" фото
    TestimonialsSection.vue   — карусель отзывов
    VisitSection.vue          — часы работы + форма бронирования со слотами
    AppFooter.vue             — подвал + подписка на рассылку
  data/
    menu.js                   — позиции меню (текст, цены)
    flavors.js                — вкусовые ноты для колеса вкуса
    testimonials.js           — отзывы
  composables/
    useFlavor.js              — общее состояние выбранного вкуса

netlify/functions/
  _shared.js                  — общая логика отправки сообщений в Telegram
  booking.js                  — бронь стола: проверяет занятость слота, шлёт в Telegram
  newsletter.js                — подписка на рассылку → в Telegram
```

## Как работают заявки

Формы не отправляют email и не используют сторонние платные сервисы — они шлют
сообщения прямо вам в Telegram через собственного бота. Бронь дополнительно
проверяет, сколько столов уже занято на выбранное время (через Netlify Blobs —
встроенное хранилище, отдельную базу поднимать не нужно), поэтому гость сразу
видит "забронировано" или "это время занято", не дожидаясь ответа человека.

Пока в `src/config.js` стоит `DEMO_MODE = true`, формы работают "понарошку" —
показывают результат, но никуда не отправляют данные. Как подключить всё
по-настоящему — в файле `DEPLOY.md`.

## Что редактировать в первую очередь

- **Тексты и цены** — `src/data/menu.js`
- **Цвета и шрифты** — переменные `:root` в начале `src/style.css`
- **Адрес и часы работы** — `src/components/VisitSection.vue`
- **Фото** — сейчас в галерее и карточке "о нас" используются CSS-паттерны вместо
  реальных фотографий (чтобы не тянуть чужие снимки). Замените блоки с классами
  `.polaroid-photo` и `.about-visual` на свои `<img>`.
