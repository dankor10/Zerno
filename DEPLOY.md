# Как выложить сайт в интернет — подробно, с нуля

Итоговая схема: **GitHub** хранит код → **Netlify** собирает сайт и раздаёт его
по адресу вида `zerno-coffee.netlify.app` (бесплатно, с HTTPS) → заявки с форм
летят в **Telegram** через встроенную функцию Netlify, с мгновенной проверкой
свободных столов.

Настройка — один раз, минут 30–40. Дальше — просто `git push`, и сайт
обновляется сам.

---

## Часть 1. Залить код на GitHub

Если аккаунта нет — зарегистрируйтесь на [github.com](https://github.com).

Откройте терминал в папке `zerno-coffee` и выполните по очереди:

```bash
git init
git add .
git commit -m "Первая версия сайта"
```

Дальше на сайте GitHub: **New repository** → название, например `zerno-coffee`
→ **Create repository**. Ничего из предложенных чекбоксов ("Add README" и
т.п.) не отмечайте — репозиторий должен остаться пустым, иначе следующая
команда не сработает.

GitHub покажет три команды — скопируйте и выполните их в терминале:

```bash
git remote add origin https://github.com/ВАШ_НИК/zerno-coffee.git
git branch -M main
git push -u origin main
```

Обновите страницу репозитория на GitHub — файлы проекта должны появиться там.

---

## Часть 2. Создать Telegram-бота

1. В Telegram найдите **@BotFather** (это официальный бот Telegram для
   создания ботов) и напишите ему `/start`.
2. Отправьте `/newbot`.
3. Придумайте имя бота (то, что видят люди) — например `ЗЕРНО Заявки`.
4. Придумайте username бота — обязательно должен заканчиваться на `bot`,
   например `zerno_orders_bot`.
5. BotFather пришлёт сообщение с токеном — длинная строка вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Скопируйте и сохраните
   её — это `TELEGRAM_BOT_TOKEN`. Никому его не показывайте — с этим токеном
   можно писать от имени бота.

### Узнать свой chat_id

Боту нужно знать, куда слать сообщения — в личку вам, или в общий чат/канал
для сотрудников.

**Если заявки должны приходить лично вам:**

1. Найдите только что созданного бота в Telegram (по username) и нажмите
   **Start** — отправьте ему любое сообщение, например "привет".
2. В браузере откройте адрес (замените `<TOKEN>` на ваш токен):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
3. В открывшемся JSON найдите `"chat":{"id":123456789,...}` — число после
   `"id":` и есть ваш `TELEGRAM_CHAT_ID`.

Если в ответе пусто `"result":[]` — значит бот ещё не получил ни одного
сообщения. Напишите ему что-нибудь ещё раз и обновите страницу.

**Если заявки должны приходить в общий чат сотрудников:**

1. Создайте группу в Telegram, добавьте туда бота.
2. Напишите в группе любое сообщение.
3. Откройте тот же адрес `getUpdates` — найдите `"chat":{"id":-1001234567890,...}`
   (у групп id отрицательный, со знаком минус — это нормально, скопируйте
   вместе с минусом).

## Часть 3. Подключить Netlify

1. Зайдите на [netlify.com](https://netlify.com) → **Sign up** → войдите
   через GitHub (проще всего, не нужно придумывать отдельный пароль).
2. **Add new site → Import an existing project → Deploy with GitHub**.
3. Выберите репозиторий `zerno-coffee`.
4. Netlify сам подхватит настройки из `netlify.toml`, но на всякий случай
   проверьте:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
5. Нажмите **Deploy site**.

Через 1–2 минуты сайт будет жить на случайном адресе вроде
`sparkly-cupcake-42.netlify.app`. Поменять на что-то осмысленное можно в
**Site settings → Domain management → Options → Edit site name** — например
на `zerno-coffee` (если имя свободно), тогда адрес станет
`zerno-coffee.netlify.app`.

С этого момента **любой `git push` в main автоматически пересобирает и
обновляет сайт** — заново заходить в Netlify не нужно.

*Позже, если купите настоящий домен (zerno-coffee.ru и т.п.) — там же, в
Domain management, есть Add a domain, и Netlify подскажет, какие записи
прописать у регистратора.*

## Часть 4. Передать Netlify токен бота (переменные окружения)

Токен и chat_id **нельзя** писать прямо в код — иначе их увидит любой
посетитель сайта через инструменты разработчика в браузере. Правильное
место — переменные окружения Netlify, они видны только серверным функциям.

1. В панели Netlify откройте ваш сайт → **Site configuration** →
   **Environment variables**.
2. **Add a variable** → добавьте:
   - `TELEGRAM_BOT_TOKEN` = токен, который дал BotFather
   - `TELEGRAM_CHAT_ID` = число, которое вы нашли через `getUpdates`
3. Сохраните.
4. Зайдите в **Deploys** → **Trigger deploy → Deploy site**, чтобы Netlify
   пересобрал сайт уже с новыми переменными (при первом сохранении
   переменных пересборка не запускается автоматически).

---

## Часть 5. Включить боевой режим на сайте

Сейчас формы работают "понарошку" — красиво показывают результат, но никуда
не отправляют данные. Чтобы включить реальную отправку:

1. Откройте `src/config.js` в проекте.
2. Поменяйте:
   ```js
   export const DEMO_MODE = true
   ```
   на:
   ```js
   export const DEMO_MODE = false
   ```
3. Сохраните, закоммитьте и запушьте:
   ```bash
   git add src/config.js
   git commit -m "Включаю боевой режим форм"
   git push
   ```

Netlify сам пересоберёт сайт за минуту. Готово — теперь бронь и подписка
реально уходят в Telegram.

---

## Часть 6. Проверить, что всё работает

1. Откройте свой сайт на `ваш-сайт.netlify.app`.
2. Заполните форму брони любыми тестовыми данными, отправьте.
3. В Telegram должно прийти сообщение вида "☕ Бронь — ЗЕРНО, ✅ Подтверждено
   автоматически (1/4)".
4. Отправьте ещё 3 брони на то же время — 4-я и 5-я должны показать на сайте
   "мест уже нет", а вам в Telegram придёт пометка "⚠️ мест на это время уже
   нет".
5. Проверьте подписку на рассылку — тоже должно прийти сообщение.

Если сообщения не приходят — самая частая причина: бот не получал от вас
сообщений до того, как вы взяли `chat_id` (тогда `getUpdates` был пуст и id
устарел), либо опечатка в токене/id в переменных окружения. Проверьте их в
Site configuration → Environment variables и пересоберите сайт.

---

## О точности брони

Проверка занятости слотов — это счётчик на Netlify Blobs, а не полноценная
система бронирования ресторана: она не учитывает, например, отмену брони
человеком (столик не освобождается автоматически) и в теории может дать
сбой при двух совершенно одновременных заявках на последнее место. Для
маленькой кофейни с потоком в несколько броней в день этого достаточно —
гость получает мгновенный ответ вместо ожидания. Если объём вырастет и
понадобится точный учёт с отменами, переносами и т.п. — это уже задача для
полноценной системы бронирования (Rezku, Poster, TableCheck и подобные,
либо своя база данных) — дайте знать, могу подсказать, как встроить такую
систему на сайт.

## Чек-лист перед тем, как делиться ссылкой

- [ ] Сайт открывается на `ваш-сайт.netlify.app`
- [ ] `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` заданы в Netlify и сайт
      пересобран после этого
- [ ] `DEMO_MODE = false` в `src/config.js`
- [ ] Тестовая бронь пришла в Telegram, "переполненный" слот показывает отказ
- [ ] Подписка на рассылку пришла в Telegram
- [ ] Адрес, телефон и часы работы в `VisitSection.vue` — настоящие
- [ ] `CAPACITY_PER_SLOT` в `netlify/functions/booking.js` выставлен под
      реальное число столов
- [ ] Открыли сайт с телефона — всё читается и не съезжает
